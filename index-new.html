User Accounts

Accounts are stored locally in this browser. Passwords are saved only as SHA-256 hashes — never in plain text. Roles decide what each person may change: Admin (everything, incl. users & settings), Receptionist (patients, appointments, billing, lab orders), Pharmacist (medicines & dispensing), Lab Technician (lab tests & results).

Cloud Sync

Optional. Create one cloud account here and sign in with the same account on every device you use (this phone, the reception desk, the pharmacy counter) — your clinic data then follows you: entries save on the device even with no internet, and when the internet returns they sync automatically. The sync pill in the sidebar always shows the state. This cloud account is separate from the staff logins in User Accounts: staff accounts decide who may do what inside the app; the cloud account only carries the same data between your devices.

Cloud sync is not configured in this copy. Everything keeps working locally in this browser — no data is sent anywhere.

Data Backup

Download a complete backup of all clinic data — patients, doctors, appointments, invoices, pharmacy stock, lab records and user accounts (passwords stay hashed) — as a single JSON file, and keep it somewhere safe. Restoring a backup replaces all current data with the backup's data; before anything is replaced, the current data is kept aside in this browser as a safety copy.

Demo & Data

Load the demo data set to explore a fully working clinic, or erase everything and start fresh. Data is stored in this browser (localStorage) and — only while you are signed in to Cloud Sync — mirrored to your own cloud account. Demo data is never synced.

About MediCore

MediCore v1.4.1 — a single-file clinic & hospital management system with user login and role-based access control. It ships with no default accounts — the first Admin account is created on first run, and demo accounts exist only if you explicitly load the demo. No installation required: open this file in any modern browser. The Pharmacy is batch-based: stock comes in only through purchase records (each batch with its own buy price and expiry), sales consume batches earliest-expiry first, and the profit figures are net of recorded expenses. The Pharmacy Scan button opens the camera and reads the medicine name, company, pack size, batch, expiry and printed price off a packet into the form for checking — nothing is saved without a tap on Save. This personal edition also offers optional cloud sync (Settings → Cloud Sync) through your own Firebase account; without it, everything works fully offline in this browser. Figures are estimates for management use; always verify critical records.
